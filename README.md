# Ludo Royal

Jeu de Ludo local à quatre joueurs, pensé pour téléphone Android et navigateur.

## Jouer

- Site : https://nwepoxy3d-rgb.github.io/LudoRoyal/
- Sur Android : ouvrir le site dans Chrome, puis menu ⋮ → **Installer l'application** ou **Ajouter à l'écran d'accueil**.
- Le jeu fonctionne hors ligne après son premier chargement.

## Règles incluses

- 4 joueurs locaux, 4 pions chacun.
- Il faut obtenir un 6 pour sortir un pion de sa maison.
- Un 6 ou une capture donne un tour supplémentaire.
- Cases étoilées protégées, captures et arrivée avec le nombre exact.
- Dé CSS 3D et animation de saisie du pion à la sortie de maison.

Le dépôt contient une PWA web installable. Ce n'est pas un APK Android natif.
